# Ветви — проект для Netlify

Готовый редактор заметок в виде дерева. В этой версии для входа нужен только ваш пароль — аккаунт ChatGPT не нужен.

Левая панель с деревьями, верхняя панель и правый редактор сворачиваются кнопками на узкой полосе над рабочим пространством. Кнопка меню слева возвращает список деревьев. Выбранная ветка и текст при этом сохраняются. Повторное нажатие раскрывает панель.

## Как выложить на Netlify

Для этого проекта используйте подключение GitHub или Netlify CLI. Простого перетаскивания папки `dist` в Netlify Drop недостаточно: кроме страницы нужны серверные функции входа и сохранения.

### Вариант 1: через GitHub и сайт Netlify

1. Распакуйте архив `vetvi-netlify.zip`.
2. Создайте репозиторий на GitHub и загрузите в него **содержимое** папки проекта. Файл `netlify.toml` должен лежать в корне репозитория рядом с `package.json`. В архиве уже есть исходники, функции, инструкция и готовая сборка. Реального пароля и пользовательских заметок в архиве нет.
3. В Netlify выберите **Add new project → Import an existing project**, подключите GitHub и выберите этот репозиторий.
4. Проверьте настройки сборки:
   - Build command: `npm run build`
   - Publish directory: `dist`
   - Functions directory: `netlify/functions`
   - Node.js: 22.12 или новее (в конфигурации задана ветка 22).
5. В настройках проекта Netlify откройте **Environment variables** и добавьте две переменные:

| Имя | Что вписать |
| --- | --- |
| `VETVI_PASSWORD` | Ваш пароль входа, минимум 12 символов. Лучше длинный случайный пароль из менеджера паролей. |
| `VETVI_SESSION_SECRET` | Другую случайную строку минимум из 32 символов. Это служебный ключ, его не нужно вводить при входе на сайт. |

Если Netlify предлагает выбор области действия переменной, включите **Functions**. Не вписывайте эти значения в `netlify.toml`, исходники или GitHub. Для получения случайного служебного ключа при установленном Node.js можно открыть терминал в папке проекта и выполнить `npm run secret`; скопируйте только сгенерированную строку.

6. После добавления переменных запустите **новую публикацию** через Deploys → Trigger deploy. Если первый deploy уже произошёл до настройки пароля, просто запустите ещё один.
7. Откройте HTTPS-адрес сайта и введите значение `VETVI_PASSWORD`. Первое дерево создастся после успешного входа.

Хранилище Netlify Blobs подключается через функции автоматически. Создавать отдельную базу вручную не нужно. Записи основного сайта сохраняются между публикациями; предварительные публикации используют отдельные хранилища.

### Вариант 2: через Netlify CLI

Если предпочитаете терминал и у вас установлен Node.js:

```text
npm ci
npx netlify-cli login
npx netlify-cli sites:create
npx netlify-cli link
```

Выберите созданный сайт в команде `link`. В веб-настройках этого сайта добавьте две переменные из таблицы выше, затем выполните:

```text
npx netlify-cli deploy --build --prod
```

Пароли не передавайте в аргументах команд, чтобы они не остались в истории терминала.

## Что находится в проекте

- `src/` — редактор, дерево, сворачиваемые панели и шифрование.
- `public/` — стартовая HTML-страница и значок.
- `dist/` — готовая сборка страницы; Netlify пересоберёт её из исходников.
- `netlify/functions/` — вход, выход и сохранение заметок.
- `netlify/lib/` — проверка пароля, сеансов и работа с Netlify Blobs.
- `netlify.toml` — настройки публикации.
- `tests/` — проверки защиты данных и сохранения.

## Работа с заметками

Нажмите на карточку, чтобы писать. Кнопки «Влево», «Вверх», «Вправо» добавляют дочернюю ветку. Карточки и холст можно перетаскивать. Кнопка «План» показывает структуру списком.

Изменения сохраняются автоматически. Проверяйте надпись «Сохранено» перед закрытием страницы. При ошибке сети или конфликте двух вкладок доступна текстовая копия через «Экспорт». Текстовая копия не защищена паролем.

Данные шифруются в браузере перед отправкой в хранилище; сервер отдельно проверяет пароль и защищает доступ к API. Это личное пространство с одним общим паролем, а не многопользовательская система. Все, кому вы сообщите пароль, получат доступ к одному дереву заметок.

Без старого пароля расшифровать заметки нельзя. Не меняйте `VETVI_PASSWORD` после начала работы простым редактированием переменной: уже сохранённые записи остаются зашифрованными прежним паролем. Для смены пароля с переносом данных нужна отдельная операция перешифрования, которой пока нет в интерфейсе. `VETVI_SESSION_SECRET` можно заменить с новым deploy — это завершит текущие сеансы без изменения шифрования заметок.

Сеанс действует до 12 часов; кнопка «Заблокировать» завершает его раньше. Лимит текущего хранилища — примерно 2 МБ текста и структуры. Сохраняйте резервные текстовые копии важных заметок. Заметки из предыдущего сайта ChatGPT не входят в исходники и автоматически на Netlify не переносятся.

## Проверки и локальная разработка

```text
npm ci
npm test
npm run build
```

Проверены: сборка страницы и функций, типы редактора, отклонение неверного пароля, запрет чтения/записи без сеанса, срок действия и отзыв сеанса, ограничение попыток входа, шифрование и восстановление заметок, конфликт версий. Тесты используют официальный локальный эмулятор Netlify Blobs. Кнопки сворачивания проверены в браузере. На вашем аккаунте Netlify публикация ещё не выполнена: её нужно завершить по шагам выше.

Для работы с Netlify Dev после настройки проекта: `npx netlify-cli dev`. Не помещайте личные заметки в файлы исходников или тесты.

## Если что-то не работает

- **«Владелец сайта ещё не настроил пароль»**: проверьте обе переменные, область Functions и выполните новый deploy.
- **Страница есть, вход не работает**: убедитесь, что опубликованы серверные функции, а не только папка `dist`.
- **Пароль принят, но заметки не открываются**: вероятно, изменён `VETVI_PASSWORD`; верните прежнее значение и повторно опубликуйте сайт.
- **После preview не видно старых заметок**: откройте основной адрес production-сайта; preview намеренно изолирован.
- **Не сохраняется**: сохраните текст через «Экспорт», проверьте соединение и сообщения в разделе Functions в Netlify.
